# AI 记账分析

个人自用的网页端 AI 记账应用：文字或语音说一句话，AI 自动解析金额与分类，记入账本；内置月度统计、分类占比、趋势图和 AI 财务小结。

## 功能

- **一句话记账**：输入「午饭花了25」或按 🎤 语音说出，AI 提取金额/分类/日期/备注，确认后入账
- **收支管理**：支出（餐饮/交通/购物/居住/娱乐/医疗/学习/人情/日用/其他）、收入（工资/兼职/红包/理财/报销/其他）
- **统计分析**：月度收入/支出/结余、支出分类占比条形图、近 6 个月趋势、AI 月度财务小结
- **数据安全**：邮箱登录，数据云端存储，行级安全策略（RLS）保证只有本人可读写自己的账目

## 技术

| 层 | 方案 |
|---|---|
| 前端 | 单文件 HTML + 原生 JS（无构建依赖） |
| 后端 | WorkBuddy 云服务（托管 PostgreSQL + 免密钥大模型调用） |
| 语音识别 | 浏览器 Web Speech API（Chrome/Edge 支持中文） |
| AI | 云服务 LLM API：记账信息抽取（JSON 结构化输出）+ 月度财务小结 |

## 数据表

`transactions`：id / owner_id / type(income|expense) / amount / category / note / tx_date / source(text|voice) / created_at

## 本地开发

直接用浏览器打开 `index.html` 仅能看界面；云数据库、登录、AI 能力需要在发布域名下运行（服务端校验来源域名）。
